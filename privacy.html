NanoClaw Assistant: Privacy Policy

Last updated: November 3, 2026

Who uses this app

NanoClaw Assistant is a private tool used only by its owner, Arik Garbuz. It is not available to other users.

What data it accesses

With the owner's consent through Google sign-in, the app accesses the owner's Gmail (read-only), Google Calendar, Google Drive, Google Docs and Google Sheets.

How the data is used

Data is used only to answer the owner's own requests: summarizing email, preparing a daily briefing, finding documents and, with the owner's explicit approval each time, creating or updating calendar events, files and spreadsheets.

Sharing and storage

Data is not sold, shared with third parties or used for advertising. Access tokens are stored encrypted on the owner's private server. Content is processed by the AI model the owner has chosen only to fulfill his requests.

Google API Services User Data Policy

NanoClaw Assistant's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account permissions.

Contact

Questions can be raised through the owner's GitHub profile: github.com/ArikGarbuz.
