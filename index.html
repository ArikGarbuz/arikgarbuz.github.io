Arik’s Assistant

Arik’s Assistant is a private, single-user personal assistant run by Arik Garbuz on his own server. It is not offered to the public.

With the owner's permission, it reads his Gmail, Google Calendar, Google Drive, Google Docs and Google Sheets to summarize messages, prepare a daily briefing and find documents. Any change to calendar events, files or spreadsheets requires the owner's explicit approval.

Arik’s Assistant is built on the open-source NanoClaw project. Arik Garbuz is not affiliated with the NanoClaw project.
